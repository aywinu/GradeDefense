1. `src/import/notes.ts` (pure, no DOM): `notesToQuestions(text, courseId, rng, max = 20): Question[]` where Question = { id, courseId, question, choices[4], correctIndex, explain, topic }.
   - Split into sentences (handle abbreviations like "e.g.", "i.e.", decimals). Keep sentences of 8–40 words.
   - Find key terms: definitions ("X is/are/refers to/means ..."), capitalised multi-word terms, terms in the first sentence of a paragraph, and numbers with units. Score sentences by how definitional they are.
   - Build cloze questions: replace the key term with "_____", max 110 characters (trim to the clause around the blank if longer), the 3 distractors are other key terms from the same document of similar length/kind (numbers get numeric distractors), no duplicates, correctIndex randomised with rng. `explain` = the full original sentence (≤ 200 chars). `topic` = the term (≤ 24 chars, Title Case).
   - Deterministic for a given rng; never throws on any input; returns [] when nothing usable.
   Tests in src/import/notes.test.ts with a realistic 3-paragraph sample (e.g. lecture notes on photosynthesis) and fast-check properties: never throws on arbitrary strings; every question has 4 distinct choices containing the answer exactly once; question length ≤ 110.

No tests needed for this DOM-bound file, but it must type-check.
