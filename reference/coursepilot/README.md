# Pre-existing material (disclosed)

These files come from **CoursePilot**, the author's earlier project (built Oct 2026, before the Kiroween submission period). They are included only as reference input and are disclosed as required by the hackathon rules.

| File | What it is | How Deadline Defense uses it |
|---|---|---|
| `course_plan.json` | Synthetic demo semester: 6 courses, items with relative due days, points, grades | Source for the bundled demo semester (converted to the game's own format) |
| `ground_truth.json` | Synthetic syllabus assessment dates | Extra demo data, e.g. "ambiguous date" enemies |
| `priority.py` | Deterministic urgency × risk × weight scoring | Design reference only. The game's TypeScript rules in `src/core/` are new code written during the submission period |

No student data, credentials or Moodle database content is included.
